# KAGE — Кровавая луна

HTML Canvas игра о поваре, который после смены становится ниндзя. Процедурная воксельная графика, обязательные мини-игры кухни, три района для набегов и магазин.

## Запуск

Откройте index.html в современном браузере. Сборка и установка зависимостей не нужны. С Node.js можно выполнить npm start и открыть http://127.0.0.1:5173.

Графика рисуется кодом, звук синтезируется Web Audio. Интернет нужен только для необязательных шрифтов: без сети используются системные.

## День и рабочая смена

Один игровой день — одна смена в суши-баре и одна попытка набега.

- Первое задание выбирается случайно из рыбы и риса. Следующее не повторяет предыдущее; пока игр две, они чередуются. План рыбы и параметры риса зависят от случайного зерна дня. У 20% заказов повышенная сложность.
- Рыба: провести автоматически движущийся нож по дорожке трёх филе. Стрелки / WASD или экранные кнопки меняют направление. Ошибка отнимает 7% качества; движение продолжается после исправления направления.
- Рис: регулировать огонь ползунком или A/D, удерживать 65–82 °C и помешивать пробелом / кнопкой каждые 4–5 секунд. При длительном отсутствии помешивания, слишком низкой или высокой температуре готовность не растёт.
- Заказ нужно завершить целиком. Качество ниже 80% открывает набег без бафа. Результат 80–100% даёт один случайный баф.
- Esc приостанавливает работу. Потеря фокуса тоже ставит игру на паузу.
- Обновление страницы посреди смены начинает тот же заказ заново. Завершённая смена и выданный баф сохраняются.
- Победа, смерть, прерывание или обновление страницы посреди набега завершают попытку и открывают следующий день. Повторного набега без новой смены нет.

## Бафы на один набег

| Баф | Эффект |
| --- | --- |
| Крепкий дух | 2 жизни вместо базовой 1 |
| Лёгкий шаг | +10% к скорости движения и рывка |
| Второе дыхание | Одно воскрешение на текущем уровне, 1 жизнь и короткая неуязвимость; убитые враги не восстанавливаются |
| Двойной трофей | Удваивает выпавшее количество тяирэ; шанс не меняется, пустая добыча остаётся пустой |
| Огненный меч | Урон ×1,03 и огненный эффект клинка |
| Ледяной меч | Урон ×1,03 и ледяной эффект клинка |

Одновременно действует только один баф. Огненный и ледяной мечи не добавляют горение или замедление. Бонус 3% считается дробно и не округляется до целого.

## Бой

| Действие | Клавиши |
| --- | --- |
| Движение | A/D или ←/→ |
| Прыжок и второй прыжок | Пробел, W или ↑ |
| Катана, серия из трёх ударов | J, X или ЛКМ |
| Рывок с краткой неуязвимостью | Shift или K |
| Пауза | Esc |

J/X можно удерживать. На сенсорных устройствах есть экранные кнопки. Звук включается вверху справа, количество крови меняется в главном меню.

У героя **одна базовая жизнь**. Попадание или падение смертельно без подходящего бафа. Враги замечают героя на соседних платформах, зовут союзников, преследуют по крыше и земле, прыгают через разрывы и атакуют выпадами. Бойцы могут отскочить от замаха. Громилы продолжают свой замах при лёгком попадании; третий удар серии прерывает его. Индикатор над врагом предупреждает об атаке, направление фиксируется перед ударом.

## Карта и оружейная

Три точки: Старый квартал, Багряные крыши, Врата рассвета. В них 8/10/12 врагов, включая 1/3/5 громил. После работы можно выбрать любую точку и повторять её в следующие дни.

За победу есть шанс получить добычу. Конкретный базовый шанс выбирается случайно для каждой базы в начале дня и виден на карте до набега. В течение дня и при перезагрузке он не меняется.

| База | Базовый шанс дня | Количество, если добыча найдена |
| --- | --- | --- |
| Старый квартал | 10–30% | 1 тяирэ |
| Багряные крыши | 30–50% | 1 тяирэ — 70%; 2 — 30% |
| Врата рассвета | 40–80% | 1 тяирэ — 40%; 2 — 30%; 3 — 20%; 4 — 10% |

Сначала проверяется шанс выпадения, затем отдельно выбирается количество. Проценты количества в таблице условные: они действуют только при успешном выпадении. Баф «Двойной трофей» удваивает количество: например, 3 превращается в 6, а 0 остаётся 0.

Каждая успешная зачистка без добычи добавляет 10 процентных пунктов к шансам **всех** баз на следующий набег, максимум до 100%. Несколько пустых зачисток складываются; выпадение любой добычи сбрасывает прибавку. Прибавка сохраняется между днями и после перезагрузки. Поражение и прерывание не приносят добычи и не меняют прибавку. Повторные зачистки работают по тем же правилам. Победа без добычи тоже засчитывается как зачистка и открывает новый день.

В магазине один новый меч: **Акацуки за 4 тяирэ**. Обычный удар наносит 2 урона вместо 1, третий — 3 вместо 2. Покупка автоматически экипирует меч; можно бесплатно переключаться на стартовую катану. Сюрикены пока не добавлены.

Баланс, зачистки, оружие, задание дня, шансы добычи, прибавка за невезение и результат работы сохраняются в localStorage. При недоступном хранилище появляется соответствующая подсказка. Сохранения версии 0.2 переносят деньги и купленное оружие.

## Файлы и проверки

- engine.js — физика, бой, враги, уровни, эффекты и бафы.
- campaign.js — дни, доступ к набегу, сохранения и магазин.
- kitchen-core.js — игровая логика рыбы и риса.
- kitchen-ui.js / work.css — интерфейс и отрисовка суши-бара.
- game.js — общий цикл игры, отрисовка платформера и управление.
- hub.js / hub.css — карта и магазин.
- index.html / style.css — оболочка.
- tests — проверки боевой логики, кухни, бафов, маршрутов и экономики.

npm test запускает проверки логики. npm run check проверяет синтаксис.
tests/browser-smoke.cjs дополнительно проверяет весь цикл в браузере, сохранения, мобильный интерфейс и запуск через file://. Для него отдельно нужен Playwright; можно указать NODE_PATH и CHROME_PATH.
